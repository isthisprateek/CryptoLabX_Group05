# Monoalphabetic Substitution Cipher and Cryptanalysis

C++17 implementation for the assignment shown in the screenshot.

## Files

- `main.cpp` - menu-driven program
- `cipher.h/.cpp` - key generation, encryption, decryption, key validation
- `analysis.h/.cpp` - letter frequency, word frequency, one/two/three-letter words, repeated words, patterns
- `cryptanalysis.h/.cpp` - iterative manual cryptanalysis, candidate substitution checks, partial plaintext, verification
- `utils.h/.cpp` - file and text helpers
- `plaintext.txt` - paste your assigned source text here
- `ciphertext.txt` - generated by the program
- `key.txt` - generated by the program; do not consult it while doing cryptanalysis

## Compile

```bash
make
```

or

```bash
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp cipher.cpp analysis.cpp cryptanalysis.cpp utils.cpp -o mono_cipher
```

## Run

```bash
./mono_cipher
```

## Suggested assignment workflow

1. Paste the required Katz-Lindell page into `plaintext.txt`.
2. Choose menu option 1 to generate a random monoalphabetic substitution key and `ciphertext.txt`.
3. Do not inspect `key.txt` during cryptanalysis.
4. Run frequency, word-frequency, and pattern analysis.
5. Use the interactive cryptanalysis menu to test cipher-to-plaintext substitutions.
6. Record each hypothesis and result in the notebook table required by the assignment.
7. Once all mappings are recovered, run final verification by re-encrypting recovered plaintext.

## Pattern representation

The program represents repeated-letter structure numerically. Examples:

- `THE` -> `0.1.2`
- `TOO` -> `0.1.1`
- `THAT` -> `0.1.2.0`
- `HELLO` -> `0.1.2.2.3`

This makes it easier to compare ciphertext words with plausible English word shapes.
